# ZalogHub — Список задач

Тестовое задание на позицию Junior Frontend Developer. Простой список задач на **React + TypeScript**, сборка через **Vite**.

## Функциональность

- Добавление задачи через поле ввода и кнопку (или клавишу Enter)
- Переключение задачи между выполненной и активной
- Удаление задачи
- Фильтрация: все / активные / выполненные
- Сохранение задач в `localStorage` — данные переживают обновление страницы
- Защита от добавления пустой задачи или строки из пробелов
- Выполненные задачи визуально отличаются (зачёркнутый текст, приглушённый цвет)
- Дополнительно: счётчик активных задач и кнопка «Удалить выполненные»

## Запуск

Требуется Node.js 18+.

```bash
# установить зависимости
npm install

# запустить dev-сервер
npm run dev

# собрать production-версию
npm run build

# посмотреть собранную версию локально
npm run preview
```

После `npm run dev` приложение доступно по адресу http://localhost:5173

## Структура проекта

```
src/
├── components/
│   ├── FilterBar.tsx    # фильтры, счётчик, очистка выполненных
│   ├── TodoInput.tsx    # форма добавления задачи
│   ├── TodoItem.tsx     # отдельная задача
│   └── TodoList.tsx     # список задач и пустые состояния
├── hooks/
│   └── useTodos.ts      # состояние задач + синхронизация с localStorage
├── App.tsx              # композиция компонентов
├── main.tsx             # точка входа
├── index.css            # стили (без сторонних библиотек)
└── types.ts             # общие типы Todo и TodoFilter
```

## Принятые решения

- Вся логика работы с задачами вынесена в кастомный хук `useTodos`, компоненты остаются «глупыми» и отвечают только за отображение.
- Чтение из `localStorage` выполняется лениво (один раз при инициализации `useState`), запись — через `useEffect` при каждом изменении списка.
- Данные из `localStorage` валидируются при загрузке: повреждённая запись не уронит приложение.
- Для идентификаторов используется `crypto.randomUUID()`.
- Доступность: связанные `label`, `aria-pressed` у фильтров, `role="alert"` у сообщения об ошибке, видимая кнопка удаления на тач-устройствах.
